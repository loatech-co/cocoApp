# J-3: iOS sweep

Branch `fix/ios-sweep`, PR #96. Stacked on #92 and rebased onto `Dev` once #92 was in.

## Done

- Deleted `SessionError.originNotAllowed`, `Connectivity.stop()` and `FormModel.visibleRecentConcepts`. `grep` under `ios/` found no callers. The only `stop()` left is `StaticWebServer`'s, which belongs to the tests.
- «sugerido» now lives in the catalog: key `capture.form.suggested`, `L10n.Capture.formSuggested`, plus its baseline entry.
- `VisibleTextTests`: new `visibleSlot` covering `Text(`, `Button(`, `Label(`, `TextField(`, `.accessibilityLabel/Hint/Value(`, `.navigationTitle(`, `.help(`, `prompt:`, `placeholder:`, `title:`, `message:`… In those slots any literal with a letter is text, single lowercase words included. `label:` is left out on purpose: in SwiftUI it is a closure, and `DispatchQueue(label:)` names a queue.
- Web: `frontend/src/locales/attributes.test.ts` reads `aria-label`, `placeholder`, `title`, `alt` and `label` (also `aria-description`, `aria-roledescription`, `aria-valuetext`) written as literals. Its one exception is the logo's `aria-label="Coco"`, and an unused exception also fails. `lint:spanish` only reads identifiers, so it did not cover this.
- `testBrandMatchesCocoTypes`: `copy-web-for-tests.sh` copies `api/openapi.v2.json` into `Web/`, and the test reads it from the bundle. It runs now, and fails instead of skipping when the copy is missing.
- The comment in `eslint.config.js` pointed at a nonexistent `inventario.test.ts`. It now points at `catalog.test.ts` and the new test.
