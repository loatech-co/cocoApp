# Phase 7 — Standards decisions (step 7.1, Part A)

Research date: **2026-10-05**. Scope: every default in `docs/plan-completo.md` §7.2–7.13.

**Decision rule (from the plan).** Criteria in order: (1) scalability, (2) maintainability,
(3) alignment with the most-adopted practice, (4) zero cost + Hostinger / Supabase / free iOS
cert compatibility, (5) migration risk. An alternative replaces a default only if it clearly
wins on 1–3 and does not lose on 4–5; ties keep the default. Tools that are beta, have no
stable version, or have had no release/maintenance in the last 6 months are **ineligible** —
when a default is itself ineligible, the best eligible option is chosen instead.

**Evidence conventions.** npm data = `npm view <pkg> version time.modified` and
`api.npmjs.org/downloads/point/last-week/<pkg>` (week 2026-09-28 → 2026-10-04), both read
2026-10-05. GitHub activity = `gh api repos/<repo>/commits|releases`, read 2026-10-05. Pages
without a publication date are cited with "accessed 2026-10-05".

## Final decisions — fixed 2026-10-05

The 7.1 stop was replaced by safeguards in the owner's autonomous mandate
(`docs/registro-autonomo.md` §5), so the decisions below were fixed by Claude
Code on 2026-10-05 under the plan's own rule, and are final for phase 7.

- **Every CHANGE in the summary is adopted** (D6, D9, D11, D16, D25-API, D27),
  with the amendments to D5, D12, D13, D15, D21, D26 and D32. Each replaces a
  default that is ineligible under the plan's own maturity rule (no release in
  6 months, 0.x, or broken on the current ESLint) or that contradicts how the
  app works today (page-jumping paginator, user-chosen sort column).
- **The contract change is a new version, not an in-place rename.** English +
  camelCase JSON changes 83 fields consumed by the web and the iOS app
  (`audit.md`). By rule 7.2 ("breaking changes → `/api/v2`"), v2 is generated
  from OpenAPI and lives next to v1; web and iOS move to v2; v1 answers with a
  `Deprecation` header, logs each use, and is removed only after **seven days
  with zero uses** (7.10 safeguard). The contraction step therefore cannot run
  before seven days after the last client moves. _(Owner, 2026-10-06: one hour
  with zero uses after the clients moved; v1 was retired that day.)_
- **Database renames** (4 tables, 17 columns, 12 enum types, 5 enum values,
  14 `timestamptz` conversions) follow expand → verify row by row → contract,
  with a tested backup before any drop.
- **Audit findings ruled on:** the unbounded history read in the dashboard is
  a measured 7.9 candidate (ADR with numbers before/after); the initial bundle
  (206 kB gzip) already exceeds the 200 kB budget, so 7.9 must bring it under
  before the gate turns on; `@prisma/adapter-pg ^7.10` next to Prisma 6 is
  fixed in the Prisma 7 step; logic living in `*.module.ts` moves out in 7.4 so
  coverage measures it; `CLAUDE.md` (606 lines) is restructured in 7.14 with
  the UI rules moved to `.claude/rules/web.md` and `CONTRIBUTING.md`.
